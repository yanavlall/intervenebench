# Manifest map

These files are metadata and contracts, not participant outcomes.

- `audits/`: append-only or frozen source-audit registries, source hashes, candidate censuses, terminal blocker adjudications, and outcome-blind schema mappings.
- `audits/independent_replication_socsci_reserve_v1.json`: deterministic orders 41--57 from the original SocSci210 strict-pool ranking, opened uniformly for the new replication census with zero inference/reveal authority.
- `audits/independent_replication_exposure_log_v1.json`: result-text incidents encountered during source lookup; every listed candidate is excluded from pristine prospective replication without recording or using the finding.
- `audits/tess_external_root_universe_v1.json`: metadata-only census of 233 first-pass nonoverlapping public TESS root projects and the deterministic 30-row second-external audit batch. It authorizes design-source acquisition but no participant extraction, inference, paid compute, or reveal.
- `audits/tess_external_root_random_lane_closure_v1.json`: hash-bound order-20 closure of the low-yield random-root lane; 0 clean, 3 conditional, and 17 terminal or blocked rows triggered the versioned stop.
- `audits/tess_targeted_intervention_universe_v1.json`: high-precision title-only, outcome-blind action-focused replacement lane with 34 candidates, a 12-row batch preserving the original hash order, and no-progress checkpoints after orders 6 and 9.
- `audits/tess_targeted_intervention_audit_registry_v1.csv`: central, freeze-order adjudication registry for the targeted lane; workers provide evidence packets but do not edit this file.
- `audits/tess_targeted_intervention_lane_closure_v1.json`: order-9 closure of the targeted lane after one strict scientific survivor (`dvwu7`), below the frozen minimum of two.
- `research/independent_replication_completion_queue_v1.json`: finite 15-candidate conversion queue replacing open-ended corpus search; replication remains blocked below 12 runnable tasks.
- `benchmark/`: generated Benchmark v1 candidate-scope and outcome-blind readiness/dependency manifests with self-checking freeze records.
- `contracts/`: source-verified decision-task candidates and outcome-blind simulator bundles.
- `research/classical_baseline_protocol_v1.json`: fixed retrospective-development classical model specification and confirmation exclusion boundary.
- `research/lora_development_gate_v1.json`: machine-readable no-go decision for cloud fine-tuning under the current data-use and sample-support constraints.
- `research/independent_replication_protocol_v1.json`: frozen 12/16-experiment completion gates, experiment-level uncertainty, random/default/classical comparisons, seeds, claim limits, and zero execution authority for the second prospective panel.
- `research/confirmation_inference_protocol_v1.json`: outcome-blind six-task confirmation matrix, exact call/cost ceiling, diagnostic ranking, and fallback rules. Every authority bit remains false; a separate execution authorization is required.
- `simulators/confirmation_call_plan_v1.json`: self-verifying definitions and prompt hashes for 1,464 planned calls plus 236 conditional outcome-free reserve calls.
- `research/cross_family_regression_protocol_v1.json`: retrospective six-task architecture-robustness scope, exact regression gates, A100 budget ceiling, and zero execution/scoring authority.
- `simulators/mistral_small_3_1_24b_source_manifest_v1.json`: public ungated Mistral commit plus the original consolidated-weight file allowlist; duplicate Transformers shards are excluded.
- `simulators/cross_family_call_plan_v1.json`: deterministic one-to-one Mistral replay of the 624 nonreserve calls used by the original primary Qwen policy.
- `../../configs/simulators/cross_family_modal_preflight_v1.json`: hash-pinned vLLM runtime, exact public-checkpoint cache boundary, three synthetic canaries, target-plan hash binding, and zero authority for every remote stage.
- `../../configs/simulators/confirmation_execution_v1.json`: pinned Modal image, six reused checkpoint groups, dependency/code/asset hashes, and zero execution authority.
- `splits/benchmark_v1_canonical_split_preflight.json`: executable scale and dependency gate; it is not a split assignment.
- `benchmark/supported_ordinal_compute_budget.json`: frozen engineering-pilot ceiling and stop rules; it does not authorize spending or outcome reveal.
- `benchmark/portfolio_pilot_scope.json`: frozen authority for the zero-cost five-task portfolio run. It authorizes local outcome-blind inference only and keeps reveal, paid inference, Modal, fine-tuning, and trust claims disabled.
- `benchmark/portfolio_pilot_development_reveal.json`: separate authority for revealing only the five declared development outcomes after recommendation verification; it permanently bars the five from canonical test use and freezes bootstrap and fallback rules.
- `splits/`: split records. The existing three-study split is the completed Phase 1 smoke split. `supported_ordinal_pilot.json` is a five-task engineering split for multi-experiment orchestration; its labels never became canonical assignments. Neither is the full Benchmark v1 canonical split or authorization for another reveal.

The successful response-free run is under `artifacts/portfolio_pilot/local_llama3_2_3b_20260813_v2/`. Its manifest and five recommendations are immutable envelopes. `run_attestation.json` records the exact local model digest, code hashes, zero cost, parser revision, and the fail-closed pre-run diagnostics.

The governed aggregate result is `artifacts/portfolio_pilot/development_score_v2.json`; it contains no participant rows. `development_score.json` is retained as the documented superseded fallback-debug artifact.

The Benchmark v1 manifest is regenerated with:

```bash
.venv/bin/python -m intervenebench.sequence_contracts
.venv/bin/python -m intervenebench.benchmark_v1
.venv/bin/python -m intervenebench.readiness
.venv/bin/python -m intervenebench.pilot
```

Do not manually edit the generated files in `benchmark/`. Change the audited source records or the deterministic builder, run tests, and regenerate. Human outcomes, response-derived summaries, winners, and regret never belong in these directories before the relevant reveal gate.
